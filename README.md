# Latihan ASAS Kelas 4

Aplikasi latihan soal ASAS (Asesmen Sumatif Akhir Semester) Kelas 4 MI untuk 11 mata pelajaran.
Berisi rangkuman materi per bab, latihan dengan pembahasan, simulasi ASAS berwaktu,
nilai & riwayat, serta bintang dan lencana. Bisa dipakai tanpa internet setelah dibuka sekali.

## Memasang di tablet Android
1. Buka alamat GitHub Pages aplikasi ini di **Chrome**.
2. Ketuk menu ⋮ → **Tambahkan ke layar utama** / **Instal aplikasi**.
3. Setelah itu aplikasi bisa dibuka dari ikon di layar utama, juga tanpa internet.

## Menambah atau mengubah soal
Bank soal ada di folder `data/` (satu berkas per mata pelajaran). Formatnya dijelaskan di `data/_util.js`.
Setelah mengubah isi, naikkan `VERSI` di `sw.js` agar tablet mengambil versi terbaru.
